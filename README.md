# Typing Speed Test

The same terminal typing game written twice: once in **Rust**, once in **C#**.

| File | Language | Size |
|---|---|---|
| `typing-test-rust.exe` | Rust | ~1.4 MB |
| `typing-test-csharp.exe` | C# (.NET 10, runtime bundled) | ~12.9 MB |

## Running (Windows 10/11, 64-bit)

Download either `.exe` and double-click it. Nothing else to install.

Windows may say **"Windows protected your PC"** because the files aren't code-signed:
click **More info → Run anyway**.

## How to play

- Type the sentence shown. Correct letters turn green, mistakes turn red.
- The clock starts on your first key. WPM and accuracy update live.
- Backspace fixes mistakes (the slip still counts against accuracy).
- **Enter** for the next sentence, **Esc** to quit.
